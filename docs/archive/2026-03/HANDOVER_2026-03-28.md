## 🎯 核心理解

### Nezha 和 OpenCode 的关系

**架构原则**：集成不应该破坏独立性

```
┌─────────────────────────────────────────┐
│          应用层（独立）                  │
├───────────────────┬─────────────────────┤
│   Nezha 核心      │   OpenCode 核心     │
│  - 任务调度       │  - 代码生成         │
│  - 心跳检查       │  - 代码分析         │
│  - Memory        │  - 自主决策         │
│  - Skills        │                     │
└───────────────────┴─────────────────────┘
         │                    │
         └────────┬───────────┘
                  ▼
┌─────────────────────────────────────────┐
│        互动层（松耦合）                  │
│  - OpenCodeReminderService              │
│  - CLI 命令                             │
│  - HTTP API + Basic Auth                │
└─────────────────────────────────────────┘
```

**关键点**：
- ✅ Nezha 可以独立运行（不依赖 OpenCode）
- ✅ OpenCode 可以独立运行（不依赖 Nezha）
- ✅ 集成是可选的增强功能
- ✅ 失败不影响核心功能

---

### OpenCode 提醒系统

**工作流程**：
```
Nezha Daemon (每 2 分钟)
  ↓
收集系统状态（7 项指标）
  - pending tasks
  - failed tasks
  - open issues
  - recent memories
  - total memories
  - critical tasks
  - recent learnings
  ↓
选择最佳模板（4 种）
  - urgent_reminder
  - learning_reminder
  - idle_state_reminder
  - default_reminder
  ↓
渲染消息（Handlebars）
  ↓
发送到 OpenCode Server
  ↓
AI 自主决策下一步
```

**核心价值**：
- 从被动任务执行者转变为主动工作助手
- NEVER DECLARE DONE - 持续改进
- AI 自治 - 不等待人类指示
