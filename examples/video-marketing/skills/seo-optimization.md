# SEO Optimization Skill

## Purpose
Optimize video metadata for maximum search visibility and discovery.

## Trigger Phrases
- "optimize video SEO"
- "improve video ranking"
- "optimize metadata"
- "SEO for video"

## Steps
1. Research target keywords
2. Analyze competitor rankings
3. Optimize video title
4. Write SEO description
5. Generate tag suggestions
6. Create hashtag strategy
7. Validate metadata length limits

## Tools Required
- Keyword research tools (Ahrefs, TubeBuddy)
- YouTube Studio
- Google Trends
- VidIQ

## Parameters
| Parameter | Type | Description |
|-----------|------|-------------|
| video_topic | string | Main video topic |
| target_keywords | array | Keywords to target |
| platform | string | YouTube, TikTok, Instagram |
| language | string | Content language |

## Platform Limits

| Platform | Title | Description | Tags |
|-----------|-------|-------------|------|
| YouTube | 100 chars | 5000 chars | 500 chars |
| TikTok | 150 chars | 300 chars | 5 hashtags |
| Instagram | 2200 chars | 2200 chars | 30 hashtags |
| Bilibili | 80 chars | 2000 chars | 12 tags |

## Output
- Optimized title
- SEO description
- Tag suggestions
- Hashtag recommendations
- Thumbnail text suggestions

## Anti-Patterns
- Don't keyword stuff
- Don't use clickbait that doesn't deliver
- Don't ignore character limits
- Don't forget mobile viewers
