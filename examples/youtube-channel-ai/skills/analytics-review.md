# Analytics Review Skill

## Purpose
Analyze YouTube channel performance and generate improvement insights.

## Trigger Phrases
- "review analytics"
- "check channel performance"
- "analyze video stats"
- "weekly report"

## Steps
1. Fetch YouTube Analytics data
2. Calculate key metrics
3. Compare with previous period
4. Identify top/bottom performers
5. Generate improvement recommendations
6. Create visual report

## Tools Required
- YouTube Analytics API
- Data visualization library
- Report generator

## Metrics Tracked
| Metric | Description |
|--------|-------------|
| Views | Total video views |
| Watch time | Total watch time in hours |
| CTR | Click-through rate |
| Average view duration | Average watch time per video |
| Subscribers | Net subscriber change |
| Revenue | Ad revenue (if applicable) |

## Output
- Performance summary
- Top/bottom videos
- Trend analysis
- Improvement recommendations
- Issues to address

## Anti-Patterns
- Don't ignore declining metrics
- Don't skip competitor analysis
- Don't focus only on views
- Don't neglect audience retention

## Examples

### Weekly analytics review
```
User: Review this week's analytics

AI: I'll analyze this week's performance:
1. Fetch last 7 days of data
2. Compare with previous week
3. Identify trends and anomalies
4. Generate recommendations

Results:
- Views: 12,450 (+15% vs last week)
- Watch time: 856 hours (+10%)
- Top video: "Python Tutorial" (3,200 views)
- Bottom video: "News Update" (450 views)
- CTR: 4.2% (above average)

Recommendations:
1. Create more tutorial content
2. Improve news video thumbnails
3. Optimize video descriptions for SEO
```

### Video-specific analysis
```
User: Why did my last video underperform?

AI: Analyzing video performance:
1. Check retention curve
2. Compare with similar videos
3. Analyze traffic sources
4. Review comments for feedback

Findings:
- High drop-off at 0:30 (intro too long)
- Low CTR (thumbnail not engaging)
- Limited search visibility

Recommendations:
1. Shorten intro to 10 seconds
2. A/B test thumbnails
3. Add more keywords in description
```
