# Thumbnail Design Skill

## Purpose
Generate eye-catching thumbnails for video content using AI image generation tools.

## Trigger Phrases
- "create thumbnail"
- "design thumbnail"
- "generate video thumbnail"
- "make a thumbnail for"

## Steps
1. Analyze video content and extract key themes
2. Determine platform-specific thumbnail requirements
3. Generate thumbnail concepts using AI
4. Apply text overlay if needed
5. Optimize for platform specifications
6. Export in correct format and size

## Platform Specifications

### YouTube
- Size: 1280x720px (16:9 ratio)
- Max file size: 2MB
- Formats: JPG, PNG, GIF
- Best practices: High contrast, readable text, faces visible

### Bilibili
- Size: 960x600px (16:10 ratio)
- Max file size: 2MB
- Formats: JPG, PNG
- Best practices: Clear subject, vibrant colors, Chinese text support

## Tools Required
- AI image generator (e.g., DALL-E, Midjourney, Stable Diffusion)
- Image editor (e.g., Photoshop, GIMP, Canva)
- Text overlay tool

## Anti-Patterns
- Don't use misleading thumbnails (clickbait)
- Don't use low-resolution images
- Don't ignore platform guidelines
- Don't use copyrighted images without permission
- Don't make text too small or unreadable

## Example Prompt

```
Generate a YouTube thumbnail for a tutorial video about "Building AI Agents".
Requirements:
- 1280x720px
- Show a robot/AI concept
- Include text "AI Agents Tutorial"
- Use bright, engaging colors
- Professional style
```

## Quality Checklist
- [ ] Correct dimensions for platform
- [ ] File size under limit
- [ ] Text is readable at small size
- [ ] Image is not misleading
- [ ] No copyright issues
- [ ] Consistent with channel branding
