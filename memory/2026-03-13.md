### 5. CoffeeClaw 协作经验 ⭐

**来源**：`../coffeeclaw/documents/COLLABORATION_EXPERIENCE.md`

**关键发现**：

#### 5.1 配置管理

**关键配置路径**：
```javascript
// ❌ 错误写法
config.defaults.model.primary = "openrouter/auto"

// ✅ 正确写法
config.agents.defaults.model.primary = "openrouter/auto"
```

**配置同步机制**：
- 需要映射提供商名称
- 需要同步 API Key
- 需要设置默认模型

#### 5.2 命令调用

**关键技术参数**：
```javascript
// 缓冲区大小
maxBuffer: 1024 * 1024 * 10  // 10MB

// JSON 提取正则
/\{[\s\S]*"payloads"[\s\S]*\}/

// 配置路径
config.agents.defaults.model.primary
```

**命令格式**：
```bash
openclaw agent --local --session-id "xxx" --message "..." --json 2>/dev/null
```

#### 5.3 协作模式

**角色分工**：
- Trae (编辑器 AI): 设计、分析、决策、审查
- 龙虾 (OpenClaw): 执行、操作、实现

**协作流程**：
1. 编辑器 AI 分析需求 → 设计方案
2. 编辑器 AI 调用 OpenClaw → 执行具体操作
3. OpenClaw 返回结果 → 编辑器 AI 审查完善
4. 共同提交代码

#### 5.4 安全优势 ⭐⭐⭐

**重要洞察**：
- GLM-4-Flash 的"限制"实际上是**安全特性**
- OpenClaw 使用 GLM-4-Flash 时不能直接执行代码
- 编辑器 AI 充当 OpenClaw 的"眼睛和手"
- 危险操作可以被检测和阻止
- 提供额外的安全层

**安全机制**：
```
OpenClaw (GLM-4-Flash)
  ↓ 只能生成任务描述（不能执行）
编辑器 AI (安全审查层)
  ↓ 检查任务是否安全
执行安全的任务
```

**对比**：
| 方面 | OpenRouter | GLM-4-Flash + Editor AI |
|------|-----------|-------------------------|
| **执行能力** | 直接执行（危险） | 通过 Editor AI（安全） |
| **危险操作** | 可能直接执行 | Editor AI 可以检测和阻止 |
| **安全审查** | 无 | Editor AI 作为安全层 |
| **风险控制** | 低 | 高 |

#### 5.5 遇到的挑战

1. **API Key 额度限制**
   - OpenRouter 限量免费（50 tokens/day）
   - GLM-4-Flash 完全免费，但不支持 execute
   - 需要通过编辑器 AI 执行代码

2. **Electron prompt 不工作**
   - 需要实现自定义模态对话框
   - Electron 安全限制

#### 5.5 最佳实践

1. **明确指令**：给 OpenClaw 的 prompt 要清晰具体
2. **错误处理**：始终处理 JSON 解析失败的情况
3. **配置同步**：保持配置一致
4. **渐进增强**：先实现基础功能，再优化 UI
5. **用户反馈**：根据用户反馈迭代设计

## 技术细节

### 会话文件事件类型

1. **session** - 会话开始
2. **model_change** - 模型切换
3. **thinking_level_change** - 思考级别
4. **custom** - 自定义事件
5. **message (user)** - 用户消息
6. **message (assistant)** - 助手消息
7. **message (toolCall)** - 工具调用
8. **message (toolResult)** - 工具结果

### 脚本机制

**openclaw-ask.sh 关键技术**：
```bash
# 发送消息
openclaw agent --session-id "$SESSION_ID" -m "$MESSAGE"

# 轮询响应
tail -n 100 "$SESSION_FILE" | grep -o '{"type":"message"[^}]*"role":"assistant"[^}]*}'

# 提取文本
echo "$RESPONSE" | grep -o '"text":"[^"]*"' | sed 's/"text":"//;s/"$//'
```
